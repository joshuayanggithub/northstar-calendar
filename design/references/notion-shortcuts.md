# Notion Calendar keyboard shortcuts (captured from calendar.notion.so/shortcuts, 2026-10-14)

## General
- Command menu ⌘K · Toggle sidebar ` · Theme shift⌘L · Save/confirm return or ⌘return
- Dismiss esc · Focus tab/shift-tab · Undo ⌘Z
- Select/deselect highlighted X · Add/remove selected shift/⌘-click · Multi-select shift-drag · Select all ⌘A

## Selected event
- Delete delete · Cut ⌘X · Copy ⌘C · Duplicate option-drag or ⌘D · Paste ⌘V
- Meetings: delete instantly ⌘delete · no-email variants with shift

## Workflows
- Create C · Meet with F · Scheduling link S · Join conferencing ⌘J
- Select next N · Select previous B or shiftN · Search /

## Editing chords (with selected event): E then …
- T title · D day · S start · Q end · Z timezone · J conferencing · C calendar/color
- A all-day · R repeat · P participants · L location · K links · W description · H reminders
- Meetings: Y/N/M respond · E email participants

## Views
- 1 or D day · 2–9 N-day · 0 or W week · M month
- shift⌘E weekends · shift⌘D declined · shift⌘A all-day expand
- Zoom: shift⌘. in · shift⌘, out · shift⌘0 reset

## Navigation
- . go to date · T today · optionT align today · J next period · K previous period
- Arrows move view · Z travel timezone · G-L/G-S/G-F goto pages · ? shortcuts

## Visual ground truth (week grid)
- Now indicator: red time pill in the hour gutter (e.g. 4:58AM) + line across ALL day columns, bold segment on today.
- Past events render faded/dimmed.
- Single click on empty slot: creates a draft chip immediately, editable; esc cancels.
- Drag with option = duplicate. Hold ⌘ while moving = commit instantly.
